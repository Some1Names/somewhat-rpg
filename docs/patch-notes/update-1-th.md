# 🔥 Somewhat RPG — อัปเดต 1: "The Director" 🔥

## ☢️ พลังใหม่: Aido (S-Tier)
**Furukiwa Aido — The Director** มาแล้ว! ซื้อได้ที่ Power Dealer ราคา **¥40,000**

## 🛡️ ระบบ Block / Parry / Posture
- กด **E** ค้างเพื่อ Block · กดจังหวะพอดีเพื่อ **Parry**
- Block มากไป Posture เต็ม = **Guard Break!**
- อัลติและท่าจับ ป้องกันไม่ได้

## 💀 ความตายมีราคา
- ตายเสียเงิน **5%** ให้คนที่ฆ่า

## 🎯 HEADHUNTER
- ผู้เล่นที่ฆ่ามากที่สุดในเซิร์ฟ (3 คนขึ้นไป) จะถูกตั้งค่าหัว — ทุกคนเห็นป้ายแดงเหนือหัว
- ล่าหัว Headhunter ได้ = ได้เงิน 20% ของเขา + **XP โบนัส**

## 📜 ภารกิจใหม่
- **🤠 Bounty Hunter** — รับค่าหัวกำจัดศัตรู ทำครบได้รางวัลทันที
- **⭐ Mastery Challenges** — ภารกิจเฉพาะของแต่ละพลัง
- กด **J** เปิดเมนูภารกิจ

## ⭐ Mastery
- ได้ Mastery จาก PvP, การฆ่า และหุ่นฝึก (ถึงเลเวล 10)
- แต่ละพลังปลดล็อกท่าไม่เหมือนกัน · Passive และปุ่ม G ต้องปลดล็อกด้วย Mastery
