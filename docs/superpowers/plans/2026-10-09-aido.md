# Aido Skill Set Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

> **Who runs it:** Tasks 1–10 are code only, so a **cloud session** can do them (or a local one).
> Task 11 needs **Studio** (a local session with the Studio MCP). Branch:
> `claude/vigilant-rubin-ckqtnn` (or a fresh branch off it). Read `CLAUDE.md` first.

**Goal:** Build Furukiwa Aido's S power: the Half-Life passive, the Chain Reaction overcharge, Fuse, Catastrophe, Collapse, Total Destruction, Ground Zero and the Final Cut dragon form, with placeholder visuals.

**Architecture:** One config entry (`SkillSetConfig.Sets.Aido`), a pure maths module (`AidoMath`, unit tested), a shared server module (`AidoUtil`) that owns the set's rules for every blast (Half-Life, Burnt, Fallout, aftershocks, the form's bigger blasts), one Skills module per move, small hooks in shared systems (ranged swap in a form, projectile `onStop`, the Half-Life passive behaviour, two SkillBar fixes), and a client `AidoEffects` module loaded like `PhotoshopEffects`.

**Tech Stack:** Roblox Luau; Lune for `tests/*.spec.luau`; StyLua (parse check) and selene (undefined variables) in `~/.cargo/bin`.

**Spec:** `docs/superpowers/specs/2026-10-09-aido-design.md` (every number and name below comes from it).

## Global Constraints

- Damage only through `Damage.Deal(player, humanoid, amount, { stat = "Superliminal", skillSet = "Aido", ... })`. Burnt only through `StatusEffects.Apply(humanoid, "Burnt", { source = player, stat = "Superliminal", skillSet = "Aido", stacks = n })`.
- Moving or holding a player: `CrowdControl.CanControl(model)` first, then `Begin`/`End` (held) or `Apply(model, seconds)`. Flying characters (`Flying` attribute) aren't pulled.
- His own blasts never hurt him (exclude his character in every target search).
- Visuals: client only, through `skillEffects:FireAllClients(kind, ...)`. Try `Aido/<Name>` (`VFX.Find`) first, else a red-tinted `Shared/*` prefab. No stock-particle "final" looks (`CLAUDE.md`). UI is square (no `UICorner`).
- Match the surrounding style: a header comment per module, a `CONFIG` table with units in comments, tabs, the existing helpers.
- Don't invent Studio instances. Anything missing (the `Aido` Tool, `FissionSeed`, the dragon, animations, prefabs) must fail quietly and be listed for Task 11.

## Review Focus

1. **Final Cut ending in every way** (Revert, 12 s, death, unequip, leaving): the `FinalCut` attribute, the dragon copy, the hidden body, the camera limit and the Atomic Breath swap must all undo; nothing leaks into his next life. (Task 8 step: end it each way and check the attribute and the dragon folder are gone.)
2. **A target dying, respawning or leaving mid-move** (Fuse stuck on them, Collapse pulling them, a Ground Zero countdown): no errors, no damage to the new body. (Steps in Tasks 3, 5, 7.)
3. **Chain Reaction aftershocks not snowballing:** aftershocks never make Fallout or more aftershocks; Fuse and Atomic Breath never make aftershocks. (AidoUtil unit of behaviour, Task 2 step.)
4. **Fallout stacking:** several patches on one spot (C's six blasts, V's field) give at most 1 Burnt stack per second per patch, and Burnt's own `maxStacks` (3) still caps it. (Task 2 step.)
5. **The SkillBar with a second overcharge set and a non-Luminance form:** no error from `form.minimumToStart` being nil, the meter in Aido's red, Mandela's still green. (Task 1 step.)

Lune vectors floor small errors to float32, so compare with a tolerance (1e-3).

### Task 2: AidoUtil (blasts, Fallout, aftershocks) and the Half-Life passive

**Files:**
- Create: `src/ServerScriptService/AidoUtil.luau`
- Modify: `src/ServerScriptService/Passives.luau` (a `behaviours["Half-Life"]`)

**Interfaces:**
- Produces:
  - `AidoUtil.enemiesWithin(character, centre: Vector3, radius: number) -> { {model, humanoid, root} }` (sphere, alive, not his character; the `BlackHole.findTargets` pattern).
  - `AidoUtil.groundAt(position: Vector3, ignore: {Instance}) -> Vector3` (raycast down 60 studs; the position itself if nothing).
  - `AidoUtil.blast(player, character, centre: Vector3, spec) -> { [Humanoid]: number }` (damage dealt per humanoid). `spec = { radius, damage, edgeDamage?, burnt?: number, fallout?: { radius, duration } | false, aftershocks?: boolean, form?: boolean, struck?: { [Humanoid]: number }, maxHits?: number, kind: string }`. It: scales `radius` by `form.blastScale` when `spec.form` and he's `InForm`; deals `falloff` damage when `edgeDamage` is given (else flat); ×(1 + `burntBonus`) on targets already Burnt (checked **before** this blast's own Burnt); applies `burnt` stacks; counts hits in `struck` and skips a humanoid at `maxHits`; starts Fallout (passive size unless `spec.fallout` gives one; none when `false`); schedules aftershocks when `aftershocks` and `Overcharge.IsActive(player, "Aido")`; fires `kind` to clients with `(centre, radius)`.
  - `AidoUtil.fallout(player, character, centre, radius, duration)`: every 1 s, 1 Burnt stack to each enemy inside; fires `"Fallout"(id, centre, radius, duration)` and `"FalloutEnd"(id)`.
  - Aftershocks: `count` at `AidoMath.scatter(centre, radius * spread)`, after `delay`, each a `blast` with `damage = spec.damage * share`, `radius = aftershock.radius`, `fallout = false`, `aftershocks = false`, no Burnt bonus (`noBonus = true`), `kind = "Aftershock"`.
  - Passives `"Half-Life"`: `InForm(character, "Aido")` → `amount * (1 - set.form.damageReduction)` (any damage); else `amount`.
- Consumes: `AidoMath` (Task 1), `Overcharge.IsActive`, `StatusEffects.Has/Apply`, `Damage.Deal`.

- [ ] **Step 1:** Write AidoUtil and the passive behaviour.
- [ ] **Step 2:** Re-read against Review Focus 3 and 4: aftershocks pass `aftershocks = false` and `fallout = false`; each Fallout patch tracks its own last-tick per humanoid so one patch gives at most 1 stack per second.
- [ ] **Step 3:** StyLua and selene; commit `"Aido: blasts, Fallout, aftershocks and Half-Life"`.
